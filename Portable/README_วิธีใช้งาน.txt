================================================================================
                    DIGITAL EVIDENCE - FORENSIC PROCESSING SUITE
                           (Portable Standalone Edition)
================================================================================

ยินดีต้อนรับสู่ชุดโปรแกรมพกพาประมวลผลพยานหลักฐานดิจิทัล (Digital Evidence)
ออกแบบสำหรับการใช้งานบน Windows โดยตรง รวดเร็ว แม่นยำ และปลอดภัย 100%

--------------------------------------------------------------------------------
📁 โครงสร้างโฟลเดอร์ในชุดพกพา
--------------------------------------------------------------------------------
1. [DIGITAL_EVIDENCE.lnk] (ไอคอนตรา EVIDENCE สีน้ำเงิน-ทอง)
   - ดับเบิลคลิกเพื่อเปิดหน้าเมนูควบคุมหลักทันที
   - หรือ "ลากโฟลเดอร์รูปภาพมาหย่อนทับไอคอนนี้" เพื่อประมวลผลทันที!

2. [INBOX_SLIPS]
   - โฟลเดอร์สำหรับวางรูปสลิปธนาคาร (โหมดสลิป 1 ใบ 1 หน้า A4 กึ่งกลาง)

3. [INBOX_CHATS]
   - โฟลเดอร์สำหรับวางรูปแคปแชทการสนทนา (โหมดแชท Smart Slicing)

4. [OUTPUT]
   - โฟลเดอร์รับไฟล์เอกสารผลลัพธ์:
     * เล่มพยานหลักฐาน PDF พร้อมแถบ Header & Footer Evidence Ribbon
     * ตารางสารบัญสลิป Excel (มีลิงก์คลิกเปิดหน้า PDF ได้ทันที)
     * ไฟล์ข้อมูล JSON โครงสร้างหลักฐานดิจิทัล

5. [core]
   - โฟลเดอร์เก็บเครื่องยนต์ประมวลผล PyMuPDF C-Binding และระบบตัดต่อภาพ

--------------------------------------------------------------------------------
🚀 วิธีใช้งาน 2 รูปแบบง่ายๆ
--------------------------------------------------------------------------------
[วิธีที่ 1] แบบเมนูโต้ตอบ (Interactive Mode):
  1. นำรูปภาพไปวางในโฟลเดอร์ INBOX_SLIPS หรือ INBOX_CHATS
  2. ดับเบิลคลิกเปิดไฟล์ `DIGITAL_EVIDENCE.lnk` (หรือ `DIGITAL_EVIDENCE.bat`)
  3. กดเลือกตัวเลข 1 หรือ 2 ตามโหมดที่ต้องการ
  4. ระบบจะประมวลผลเสร็จในไม่กี่วินาที และเปิดโฟลเดอร์ OUTPUT ให้ทันที

[วิธีที่ 2] แบบลากวางด่วน (Drag & Drop Mode):
  1. ลากโฟลเดอร์รูปภาพ หรือไฟล์รูปภาพจากที่ไหนก็ได้
  2. หย่อนทับลงบนไอคอน `DIGITAL_EVIDENCE.lnk`
  3. เลือกว่าจะให้ออกเป็นโหมดสลิป หรือโหมดแชท
  4. เอกสาร PDF จะถูกสร้างขึ้นในโฟลเดอร์ OUTPUT ทันที!
