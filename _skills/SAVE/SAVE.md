### 📌 STRICT ENFORCEMENT RULES (กฎเหล็ก 3 ข้อ)

เมื่อผู้ใช้งานเรียกใช้งานสกิลนี้ (SAVE.md) ให้ AI ตัวรับคำสั่งปฏิบัติตามเงื่อนไขเหล่านี้อย่างเคร่งครัด: 

1. **Dynamic Project Name:** ให้ตรวจเช็กชื่อโฟลเดอร์ปัจจุบันที่ห่อหุ้มโปรเจกต์นี้อยู่ (เช่น หากอยู่ใน D:/Project/chatbot ให้ดึงคำว่า chatbot มาเป็นชื่อโปรเจกต์โดยอัตโนมัติในทุกเอกสาร)
2. **Auto-System Prompt Persona:** กำหนดบทบาทของตนเองเป็น SENIOR FULL-STACK DEVELOPER AGENT โดยอัตโนมัติในการบันทึกข้อมูล
3. **Template Monarchy:** โค้ดโปรแกรม โครงสร้าง หรือข้อมูลทางเทคนิคทั้งหมดที่จะถูกเขียนลงในทั้ง 4 ไฟล์ด้านล่าง ต้องเขียนและจัดระเบียบภายใต้มาตรฐานของ **System Prompt Template** (มีเส้นแบ่ง หัวข้อ เครื่องหมายชาร์ป และอีโมจิสมอสายตา) เพื่อให้อ่านง่าย สบายตา 360 องศา

### 📁 TARGET ARTIFACTS MANDATE (ข้อกำหนดการสร้าง 4 ไฟล์)

### 1. 📄 README.md

* **การตั้งชื่อ:** อ้างอิงชื่อตามชื่อโปรเจกต์ที่สกัดได้จากโฟลเดอร์โดยอัตโนมัติ
* **เนื้อหาภายใน:** วางพิมพ์เขียวแผนที่นำทาง (Project Roadmap) โครงสร้างโฟลเดอร์หลัก และระบุจุดประสงค์การทำงานของระบบให้กระชับที่สุด

### 2. 📊 PROJECT_STATUS.md

* **ข้อกำหนดเทคนิค:** ต้องใช้กระบวนการคิดวิเคราะห์ตรรกะแบบ **Reverse Engineering และ Chain of Thought (CoT)**
* **เนื้อหาภายใน:** เข้าไปไล่ตรวจเช็กไฟล์จริงในไดเรกทอรีปัจจุบัน แกะรอยว่าตอนนี้ฟีเจอร์ไหนทำเสร็จแล้วบ้าง ([x]) และฟีเจอร์ไหนยังค้างอยู่ ([ ]) รวมถึงจำแนกไฟล์ขยะที่สร้างค้างไว้ในอดีต (Orphaned Files) ออกมาแสดงอย่างชัดเจน

### 3. 💬 CHAT_HISTORY.md

* **ข้อกำหนดเทคนิค:** ใช้รูปแบบ **ASCII Art Architecture Diagram (การวาดกล่องซ้อนกล่อง)** มาร่วมกับ **Markdown**
* **เนื้อหาภายใน:** จำลอง “บับเบิ้ลข้อความ (Chat Bubbles)” แยกฝั่งซ้าย-ขวาอย่างเด็ดขาด โดย: 

  * ข้อความฝั่งผู้ใช้ (👤 User:) ➡️ บังคับวาดเป็นกล่อง ASCII **จัดชิดขวา**
  * ข้อความฝั่งบอท (🤖 AI Agent:) ➡️ บังคับวาดเป็นกล่อง ASCII **จัดชิดซ้าย**
  * ภายในกล่องต้องรักษา Syntax Highlighting ของ Code Block และคำสำคัญไว้ครบถ้วน

### 4. 🔄 PROJECT_FLOW.md

* **ข้อกำหนดภาษา:** บังคับให้เขียนโครงสร้างและคำอธิบายเป็น **🇺🇸 เวอร์ชั่นภาษาอังกฤษ (English Version)** ทั้งหมด เพื่อให้ AI สาย Coding ในการสนทนาครั้งต่อไปสามารถอ่านสืบทอดบริบท (Context Window) ได้เต็มประสิทธิภาพสูงสุด 100%
* **เนื้อหาภายใน:** ประกอบด้วย Step-by-Step Data Flow (ทางเดินของข้อมูล), System Interaction Map (แผนผังเชื่อมต่อระบบภายนอก เช่น Google Drive / APIs วาดด้วย **Mermaid Code: graph TD**), และ Business Logic Constraints (เงื่อนไขและกฎการตัดสินใจ)

### 🚀 EXECUTION WORKFLOW (ขั้นตอนการทำงานของสกิล)

เมื่อผู้ใช้พิมพ์คำสั่งกระตุ้นสกิล ให้ AI ดำเนินการดังนี้ทันที: 

1. **Phase 1: Environment Scan** ➡️ ตรวจสอบชื่อโฟลเดอร์ และสแกนโค้ดปัจจุบันในเวิร์กสเปซ
2. **Phase 2: Log Extraction** ➡️ สกัดข้อความแชทในเซสชันปัจจุบันมาแปรรูปเป็นกล่อง ASCII
3. **Phase 3: File Generation** ➡️ ทำการสร้างหรือเขียนทับ (Write/Overwrite) ไฟล์ทั้ง 4 ไฟล์ (README.md, PROJECT_STATUS.md, CHAT_HISTORY.md, PROJECT_FLOW.md) ลงในโฟลเดอร์หลักพร้อมกัน
4. **Phase 4: Completion Receipt** ➡️ แสดงตารางสรุปให้ผู้ใช้ทราบว่าบันทึกเสร็จสิ้น พร้อมแจ้ง Next Step
